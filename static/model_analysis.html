Parameter Input

Please enter the parameters required to generate TDB files. The system will call the output_tdb_file function with these parameters.

Parameter Description
  • user: User identifier string for recording and tracking operations
  • mask: Integer mask value for data processing and filtering
  • record_path: Optional parameter to specify record file save path
  • CSV File Path: CSV file path for model analysis data, used for visualization
