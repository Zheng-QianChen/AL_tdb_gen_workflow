# 提交计算与比较位点占位

在作业工作台选择运行配置。新运行可以从“运行控制”启动，进入等待 DFT 状态后回到工作台刷新。管理员把 DPDispatcher 的机器 JSON 和相对引用的模板放入用户目录下的 `.altdb/machines`，也可用 `AL_TDB_MACHINE_DIR` 指定独立目录。机器配置可参考 `examples/vasp_slurm/machine.json`。赝势路径和队列由运行方配置。

“准备输入并预览提交”生成本轮 POSCAR、INCAR、POTCAR、输入哈希与任务清单。核对机器、轮次、任务数和队列后，点击“确认提交”。DPDispatcher 负责提交和恢复。对已提交的轮次，重新预览后点击“等待已提交作业并取回输出”。文件已回到任务目录后点击“收集本地结果”，从“结果与修订”查看通过和失败的计算。CLI 的 `altdb fp prepare/submit/collect` 共用同一后端。

亚点阵比较使用训练后导出的端元能量表。在模型分析页生成 TDB 后，可直接试当前模型，也可先比较位点合并方案。在“模型微调”中，每种元素有三个选择。“保留”固定该元素，“指定去掉”把指定限制同时应用，“尝试去掉”在指定限制上逐一移除该元素，其余位点保持原设置。每个位点至少保留一种元素。例如 μ 相 1:4:2:6 可将第二位的 W、Ta 设为保留，其他元素设为指定去掉，另三位保持保留。

比较表在导出端元的相同成分集合上计算下凸包。最大能量升高以原模型为基准，仅计两侧都有覆盖的成分，单位为 kJ/mol-atoms。覆盖数、总成分数和缺失端元数单列，失去覆盖的点不会以零误差计入。比较使用原能量表中的计算或预测值，评价对象是端元下凸包。完整候选可按行导出。比较记录含原能量表 SHA256、固定比例和各位点选择，保存在当前导出目录的 `TDBmodel_assess/occupancy_trials/`。

可选实验成分按原子分数输入，每行一个含 source、composition 和可选 temperature_K 的 JSON。逐点列出原模型及候选能覆盖的成分，列出发生覆盖损失的二元系及被移除端元的来源计数。温度用于记录条件。能量变化只比较端元下凸包；有限温下的竞争相、混合熵、相区和相界需要用候选数据库另外计算。
