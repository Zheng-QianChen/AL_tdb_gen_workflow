# 数值与任务维护说明

本次整理将科学计算、任务调度和 HTTP 接口分开：

- `src/thermodynamics.py`：能量单位和亚点阵比例。
- `src/Hull.py`：下凸包以及沿能量轴的距离。
- `src/ml.py`：模型构造、可复制的估计器和折外 Stacking。
- `src/settings.py`：输入结构与路径校验。
- `src/storage.py`：配置、检查点的原子写入。
- `src/main_process/`：工作流、任务生命周期与亚点阵模型评估。
- `routes/`：只处理请求、任务定位和响应。
- `tests/`：数值、TDB 解析、状态恢复及接口回归。

## 数值约定

`DFT_1` 和 `DFT_2` 为整个输入晶胞的总能量，单位 eV，训练使用 `DFT_2`。
参考能 CSV 为元素的 eV/atom。形成能计算为：

```text
ΔE [kJ/mol-atoms] = (E_cell / N_atoms - Σ x_i E_ref,i) × 96.48533212331002
```

内部成分始终为 0–1 原子分数，不能原地乘 100。旧的简化模型评估接口使用百分数时，只转换独立副本。原始相的纯端元能量由计算或预测给出，不额外假定它们为零。下凸包零距离是有效结果；位于参考下凸包下方的查询点距离为负。

简化模型分数统计的是其遗漏的低能点。RMSE 为误差平方均值的平方根；恒定偏差不能被减去。没有遗漏点时记为 0。这不是整个候选空间的预测 RMSE。单亚点阵与未简化模型作为两端基准也参与比较。

Stacking 的第二层使用折外预测训练；sklearn.clone / 交叉验证保留选定模型及超参数。KNN 等模型仍须按训练折大小设置参数。少于两个训练样本不能运行 Stacking。

## 检查点与停止

`record/checkpoint.json` 是恢复的唯一入口。它引用已完整落盘的 pickle，包含迭代号、阶段、配置，以及结构、描述符、参考能文件的 SHA-256。配置或源文件变动需另建运行目录。

阶段：0 = 计算凸包并选点，1 = 等待 DFT 文件，2 = 训练，3 = 候选耗尽。每次阶段完成后保存模型，再原子替换清单。历史日志只用于查看，不决定恢复位置。

停止会等待当前同步操作和检查点完成；线程不能强行终止。同一任务重新启动必须等待旧操作退出。执行器归管理器所有，单个任务不会关闭它。不同运行任务不能同时写重叠输出路径。当前实现应使用单个服务进程，不能用多个 uvicorn worker 共享运行目录。

旧版 pickle 可能包含已缩放的成分或旧能量约定，因此拒绝自动恢复。保留旧输出，从新的运行目录重新训练。pickle 仅用于本地可信缓存，不是可交换输入格式。旧 `pkl_show_control` 设置仍能读取，但关键阶段检查点始终保存。

## TDB 边界

输出是相片段，必须结合采用一致参考态的 `ELEMENT`、`GHSER*` 和类型定义。能量转成 J/mol-formula，位点比与参考能系数保留高精度。默认将位点比归一化为总和 1。

所有声明的端元必须具有参数。阈值 `mask` 只在 CSV 中生成 `within_hull_tolerance` 标记；不删除参数，因为缺失参数可能被下游引擎解释成零能量。元素裁剪或合并亚点阵若产生未知端元，会报错，需要补充计算后再导出。

这些数值仍是基于 DFT 与机器学习的形成能近似；没有增加声子、磁性、有限温度过剩项等物理模型。语法解析通过不代表热力学评估完成。

## 验证与环境

```bash
python -m pip install -r requirements-dev.txt -c constraints-test.txt
python -m pytest -q
python -m ruff check --select F821,F822,F823 app.py main.py config.py routes src examples tests
python -m examples.demo
```

测试包含线性规划交叉核验三元凸包、偏差 RMSE、退化点集、选点耗尽、折外训练、pycalphad 参数解析与能量加权、停止/恢复、文件变化拒绝恢复、重复上传和多任务隔离。示例能量全部为人工构造。

CI 配置覆盖 Windows/Linux 与 Python 3.11/3.12；本地执行不等于远端 CI 已通过。可选 XGBoost、CatBoost、桌面 WebView 以及真实 VASP 作业不属于默认回归环境。
