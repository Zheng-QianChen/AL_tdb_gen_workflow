# AL–TDB 0.4.6

本版把文献证据、相结构选择、多个单相模型、参数优化和作业状态放进同一项目工作台。首次使用请完整解压 `AL-TDB-desktop-0.4.6.zip`，准备 Python 3.11 或 3.12，按平台运行启动入口。

| 平台 | 启动入口 |
| --- | --- |
| Windows | 双击 `Start-AL-TDB.cmd` |
| Linux | `sh Start-AL-TDB.sh` |
| macOS | `Start-AL-TDB.command` 或 `sh Start-AL-TDB.sh` |

- 从文献详情阅读 PDF、查看笔记、导入 CSV/TSV 或手动摘录。每条测量可保留来源、原表位置、温度、单位和修订；多相试样可稍后映射库相。
- 按实测体系、文献和测量项目浏览实验记录。相结构候选和本库相名分别维护，一个相可以保存多个独立 CEF 模型。
- 使用内置优化器，或通过适配器交接外部计算。结果页可检查计算设置、收敛情况和修订；作业页可查看排队、运行及完成状态。
- 完整工作台包用于跨机器恢复数据与附件；仅设置模式用于恢复当前视图。
- 首页提供 AI 协作指南。请让能读取仓库的助手从根目录的 `AGENTS.md` 开始。

发行包提供通用代码和合成示例。新建项目后，可以把自己的来源文件、实验记录和 TDB 导入本机数据目录。
